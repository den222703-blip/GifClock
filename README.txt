GIF Clock

=== Быстрый запуск (без exe) ===
1. Установи Python с python.org (галочка "Add python.exe to PATH").
2. Командой  py -m pip install PyQt6  (или python -m pip install PyQt6).
3. Запусти  run.bat  (или:  py main.py ).

=== Сборка EXE ===
Дважды щёлкни  build_exe.bat . Скрипт сам поставит PyQt6 и PyInstaller и соберёт
  dist\GifClock.exe
Папка  dist\assets  должна лежать рядом с exe — из неё берутся GIF, их можно
менять без пересборки. (Если папки рядом нет, берутся GIF, вшитые в exe.)

=== Файлы GIF ===
  assets\digits\0.gif ... 9.gif   цифры
  assets\separator.gif            одна точка-разделитель (прозрачный фон).
                                  В времени рисуется как ':' (две точки),
                                  в дате как '.'.

=== Управление ===
Значок в трее (у часов): Настройки / Разрешить перемещение мышкой / Выход.
Пока перемещение запрещено, клики проходят сквозь часы.

=== Как ведут себя часы ===
* Слой: часы ВСЕГДА ниже всех обычных окон, прямо над рабочим столом (как
  виджет). Win+D / "Свернуть все окна" / Ctrl+D их не прячут: порядок окон
  восстанавливается мгновенно (по событиям Windows) и страхуется проверкой
  4 раза в секунду.
* Время идёт ВСЕГДА: отдельный таймер времени никогда не останавливается.
* GIF-анимация (отдельный таймер) ставится на паузу, когда часы закрыты окном
  или включено полноэкранное приложение, и сразу продолжается, когда часы снова
  видны. Отключается галочкой в настройках.
* Если часы не появились: py main.py --reset . Журнал: %TEMP%\gifclock.log

=== Автозапуск ===
Настройки -> "Запускать вместе с Windows". После этого при включении ПК
открываются только часы (настройки — через значок в трее или запуск с ключом
--settings). Окно настроек само открывается только при самом первом запуске.
